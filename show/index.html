12 / 18 · TWO WAYS TO ORGANISE THE WORK

Workflow or agent?

Fixed workflow

Code chooses
the sequence.

Startup: draft → check → repair.

Agent

AI chooses
an allowed action.

Simulation: talk, refine or vote.

Both can run unattended within a defined scope.

13 / 18 · RUNNING UNATTENDED NEEDS MORE THAN A MODEL

What keeps
the routine running?

TriggerA clock or event
RuntimeA worker that stays available
StateProgress saved between runs
BoundariesChecks, limits and a stop path

You set the goal, budget and stop rules. Monitor failures, cost and manual work.
