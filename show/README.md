# Public lecture archive

18-slide, student-safe edition derived from the current presenter source. `index.html` provides a mobile reading view and the original projector layouts. `lecture-offline.html` embeds its CSS, scripts and images; links leave the offline file only when chosen. `version.json` records source hashes and the output version.

This directory deliberately contains no presenter runtime, private notes, old 8 MB fallback bundle, live API calls, credentials, automatic intake, or student submissions. Classroom counters are omitted; example numbers remain clearly dated snapshots. The original workshop wording and historical 14:00 handoff remain within the archive context.

Only the public images, original layout CSS and self-contained Three.js illustration were copied. Proof links lead to the public companion examples; slide 17 links to the workshop ideas archive.
