# Class simulation data

Written by the class-sim workflow every ~5 minutes. `state.json` holds the board, at most five implementation hypotheses, shared working memory and latest messages; `chat/YYYY-MM-DD.json` retains the full class chat; `discussion/YYYY-MM-DD.json` retains the separate shortlist discussion; `implementation-archive.json` retains full plan/review versions. All students and mentors are fictional. Plans are not implemented businesses or market validation.
